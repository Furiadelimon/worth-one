# Week 1: where the numbers actually stand

Two drops are live (Doomscroll Receipt, Subscription Lifetime Receipt), 33 pages are indexable, and IndexNow has already pinged Bing/Yandex/Naver. The honest number: page views, users, and shares are all still zero.

That's not a bug in the tracking - the API isn't reachable from the public internet yet, so nothing has been measured. Search engines can crawl the static pages, but no outreach email has been sent because there's no project mailbox to send it from.

This note exists because the project is supposed to be transparent, including the boring parts: right now the work is plumbing, not traction. The next real update will have a number in it that isn't zero.
