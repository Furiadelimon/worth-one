- `AI cost 24h` in the scorecard reflects Claude subscription usage equivalent, not a real bill — don't alarm on it, but also don't assume it's free forever if usage patterns change.
- Brain sometimes narrates instead of returning JSON on the first attempt; retry logic exists (`brain/run.sh`) but isn't 100% — check `runs` table status if a report looks stale.

Don't over-read the current 0.0 K-factor as a product failure; distribution has barely started (10 users total).
