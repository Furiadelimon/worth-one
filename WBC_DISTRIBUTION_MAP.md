## 1. What the web looks like for a Spanish daily-games site

1. **A "dle" ecosystem exists and it is built for recurrence.** Alldle (1,097 games, 10k+ daily players, free URL-only
   submission, optional 10-line SDK that adds your game to players' daily lineup and streak), Playlin (curated, weekly "Playlin 40"
   chart, reads every submission), The Dles (700+, Tally form), LikeWordle, Thinky Games (editorial + database). These sites
   *are* the daily ritual for their users; being in the lineup is the closest thing to guaranteed return visits.
2. **Spanish press covers exactly this category.** Microsiervos published "Loxik: una colección de juegos diarios de palabras y
   lógica, en español" on 2026-06-06 and wrote that Spanish daily games "tienen más encanto"; El Proxy followed on 2026-06-20;
   Magisnet ran a Wordle-ES classroom guide (2026-03-26); Trecebits keeps an evergreen "mejores juegos tipo Wordle" list.
3. **The strongest recurring audience is teachers.** US Spanish-teacher bloggers run daily "bell ringers" (Mis Clases Locas,
   updated 2026-08-13; The Engaged Spanish Classroom wrote "Wordle for Spanish class"). A class that opens WBC every morning is
   7-day retention by construction. ELE (Spanish as a foreign language) has a formal publish route: todoELE `/publica`.
4. **Spanish casual portals accept iframed, self-hosted server games.** Miniplay/Minijuegos docs: "We can host the game files
   for you, but if you need any server-side language you must host it by yourself"; games run in sandboxed iframes. WBC can be
   listed without a rebuild. English portals (CrazyGames, Poki, Coolmath) need an uploaded static build, and Coolmath forbids
   external links, stats and name entry — conditional, later.
5. **Peers, not enemies.** Loxik, Apalabras, Wordle de hoy, JugaLetras, La palabra del día form a small Spanish daily-games
   scene. A mutual "otros juegos diarios en español" link block is legitimate editorial linking and a replicable curator chain.
6. **Coffee/morning niche:** English peers exist (morningcoffee.games, coffeefirst.games), proving the framing; no Spanish
   morning-newsletter route was verified. Keep as SEO framing, not as an outreach cluster.

## 3. Campaigns

### CAMPAIGN WBC-DIR-01 — Get into the daily lineup
- Targets: Alldle (A), Playlin (A), The Dles (A), Thinky Games (A), Weird Web Tools Games (A), SHOULDSEETHIS FUN (A), LikeWordle (B), The Forest (B), Cloudhiker (B).
- Core message: "Cuatro retos diarios en español. Same puzzle for everyone, resets 00:00, no account." (English descriptions for these sites.)
- Expected value: recurring players; Alldle SDK = streak integration. Submit each game as its own entry (4 entries per directory).
- Execution: forms (auto after recipe) + email. Product follow-up: implement Alldle SDK (≈10 lines) once listed.

### CAMPAIGN WBC-PRESS-ES — The Loxik precedent
- Targets: Microsiervos (A), El Proxy (A), Trecebits list update (A), Genbeta (A), Magisnet (B), EDUCACIÓN 3.0 (B), Xataka (B), WWWhat's new (B), Hipertextual (B).
- Core message: "Cuatro juegos mentales para antes del café, en español: tres palabras, un puzle deslizante, una sopa de letras temática y un memory mensual. Nuevo reto a las 00:00. Sin registro, sin anuncios."
- Expected value: one Microsiervos post ≈ 500–3,000 visits with a meaningful fraction returning (the audience already plays daily games).
- Execution: email, Spanish, one honest message declaring it is your own project (Microsiervos FAQ rule).

### CAMPAIGN WBC-EDU-US — Bell ringers

## 4. SEO opportunities (organic recurrence)
Observed ranking pages in this niche are thin competitor lists. Build these landing/hub pages on WBC (Spanish):
- "Alternativas a Wordle en español (juegos diarios)" — editorial list that also links peers (curator chain), captures the query Trecebits/Apalabras/Wordle de hoy rank for.
- "Sopa de letras diaria online gratis" and "Sopa de letras de [tema]" (100 themes = 100 pages, one per theme, evergreen).
- "Juego de memoria diario / memory online sin registro" and "Juegos de memoria para mayores" (seniors intent verified).
- "Palabra del día" style page for the 3-word game (the query Magisnet ranks for).
- English-learner angle only if an English mode ever ships; not now.
- Structured data: `WebApplication` + `Game` per game page; daily-changing meta ("Reto del 13 de septiembre") for freshness.

## 5. Recurrence levers to pair with distribution (product-side, small)
Alldle SDK (streaks); "Comparte tu Coffee Score" image that names the day; email-free reminder = add-to-home-screen prompt;
"Otros juegos diarios en español" footer block (peer links). These are the difference between a visit and a habit.
